# DeepHire

## Multi-Modal Deep Learning Interview Assessment Platform

DeepHire is a multimodal AI system designed to evaluate interview performance using multiple measurable signals.

The platform combines:

- Resume Understanding
- NLP-based Answer Evaluation
- Speech Assessment
- Coding Assessment
- Computer Vision Features
- Explainable AI
- Personalized Learning Recommendations

---

## Research Question

Can multimodal AI signals including text, speech, coding performance and visual behavior provide a better interview assessment than traditional single-signal evaluation?

---

## Core Models

### Fine-Tuned

- DistilBERT

### Custom Trained

- Speech CNN
- Fusion Network

### Pretrained

- Whisper
- MediaPipe
- OpenCV
