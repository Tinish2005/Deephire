# Ethics and Privacy

## Non-Supported Claims

DeepHire will not attempt to infer:

- Personality
- Intelligence
- Emotions
- Truthfulness

---

## Supported Claims

DeepHire evaluates:

- Answer Quality
- Speech Quality
- Coding Performance
- Observable Visual Features

---

## Privacy Requirements

- Authentication
- Secure Storage
- User Consent
- Data Deletion Support

---

## Transparency

Users should understand why scores were generated.
