# Research Objective

## Core Research Question

Can multimodal signals improve interview assessment quality compared to single-source evaluation systems?

---

## Signals Used

### Text

Question and Answer Data

### Speech

Audio-based Communication Data

### Coding

Programming Assessment Data

### Vision

Observable Visual Behavior Data

---

## Expected Outcome

A multimodal system capable of generating:

- Interview Performance Score
- Technical Assessment
- Communication Assessment
- Learning Recommendations

---

## Scope Limitations

The system will not attempt to infer:

- Personality
- Intelligence
- Emotion
- Truthfulness

The system will only evaluate measurable behavior.
