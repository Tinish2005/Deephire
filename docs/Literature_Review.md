# Literature Review

## Existing Interview Assessment Platforms

### Pramp

Strengths:
- Peer-to-peer mock interviews
- Real interview experience

Limitations:
- No deep learning based assessment
- Limited analytics

---

### Interviewing.io

Strengths:
- Real interview environment
- Anonymous interview process

Limitations:
- Limited automated feedback
- Minimal explainability

---

### LeetCode Interview

Strengths:
- Strong coding assessment

Limitations:
- No speech assessment
- No vision assessment
- No multimodal feedback

---

## Research Gap

Most interview preparation systems focus on:

- Question and Answer Evaluation
- Coding Assessment

Very few systems combine:

- NLP
- Speech Processing
- Vision Features
- Coding Signals

into a unified assessment framework.

DeepHire aims to address this gap through multimodal assessment.
