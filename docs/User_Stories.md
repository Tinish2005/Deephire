# User Stories

## Interview Evaluation

As a candidate

I want to receive detailed interview feedback

So that I understand my strengths and weaknesses.

---

## Coding Assessment

As a software engineer

I want coding performance evaluation

So that I can improve problem solving skills.

---

## Learning Recommendations

As a student

I want personalized learning recommendations

So that I know which topics to study next.

---

## Speech Assessment

As a candidate

I want feedback on my communication quality

So that I can improve interview performance.
