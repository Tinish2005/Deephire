# Product Requirements Document

## Product Vision

Help candidates understand:

- How they performed
- Why they performed that way
- What to improve next

---

## Product Objective

Build a multimodal interview assessment platform capable of combining multiple measurable interview signals.

---

## Target Users

### Primary Users

- College Students
- Placement Candidates
- Internship Candidates

### Secondary Users

- Software Engineers
- Backend Developers
- AI Engineers

---

## Core Features

### Resume Intelligence

- Resume Upload
- Skill Extraction
- Project Extraction
- Experience Extraction

### Interview Engine

- Personalized Interviews
- Company-specific Interviews
- Role-specific Interviews
- Adaptive Questions

### Assessment

- Answer Evaluation
- Speech Assessment
- Coding Assessment
- Vision Analysis

### Recommendations

- Weak Area Detection
- Learning Roadmap
- Practice Recommendations

---

## Success Criteria

Users should receive:

- Accurate Evaluation
- Explainable Feedback
- Personalized Learning Suggestions
